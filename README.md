# TaskFlow To-Do List

A React + Vite + Tailwind CSS + React Router task organizer for DCIT 26.

## Features
- Home dashboard with task statistics and progress
- Create groups and prevent duplicate group names
- Add, complete, filter, and delete tasks
- LocalStorage persistence in the browser
- Responsive layout and active navigation highlighting
- Guide and Developers pages

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Build
Run `npm run build` to create the production build in `dist/`.

The app uses `src/pages/Groups.jsx` (plural) consistently with its import in `src/App.jsx`.
